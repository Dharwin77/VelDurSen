## Animation Timing

- **Scroll trigger:** Activates when section enters viewport (margin: -100px)
- **Once:** `true` - Animations play once only
- **Duration:** 0.6s - 0.8s depending on complexity
- **Hover effects:** 0.3s transitions

## Color Coding by Industry

| Industry      | Primary Color | Gradient Shades          |
|---------------|---------------|--------------------------|
| Healthcare    | Blue (#3B82F6)| Blue/Cyan               |
| Education     | Indigo (#6366F1)| Indigo/Purple         |
| Manufacturing | Orange (#F97316)| Orange/Amber          |
| FinTech       | Emerald (#10B981)| Emerald/Teal         |
| Retail        | Purple (#A855F7)| Purple/Fuchsia        |

## Responsive Breakpoints

- **Mobile** (< 768px): Single column, stacked layout
- **Tablet** (768px - 1024px): 2-column grids
- **Desktop** (> 1024px): 3-column grids, side-by-side layouts

## SEO Keywords Per Section

Each section contains:
- "CRM software" - 2-3×
- "cloud CRM platform" - 1-2×
- "scalable CRM systems" - 1×
- "enterprise CRM software" - 1×
- "business automation solutions" - 1×
- "customer relationship management platform" - 1×

**Total keyword density:** Optimized for natural reading while maintaining SEO value.
