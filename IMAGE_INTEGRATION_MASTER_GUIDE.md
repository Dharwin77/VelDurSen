## 🆘 Troubleshooting

### Images Not Showing?

**Check:**
1. Files are in `/public/images/industries/` folder
2. Filenames match exactly (lowercase, hyphens, .webp)
3. Dev server is running (`npm run dev`)
4. Clear browser cache (Ctrl + F5)
5. Check browser console for errors

### Images Loading Slowly?

**Fix:**
1. Re-optimize with Squoosh (lower quality)
2. Ensure images are WebP format
3. Check file sizes (should be < 150KB)
4. Verify lazy loading is working

### Wrong Colors?

**Solution:**
1. Download different images from Unsplash
2. Use Figma/Canva to adjust colors
3. Apply color overlays in image editor
