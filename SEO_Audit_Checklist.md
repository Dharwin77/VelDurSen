# VelDurSen Technologies SEO Audit Checklist

## **1. Technical SEO & Infrastructure**
- [x] **Dynamic Meta Tags (`react-helmet-async`)**: Ensure all pages have unique titles and descriptions.
- [x] **Create 404 Page**: Optimized custom 404 page with links to key sections.
- [x] **Sitemap.xml**: Comprehensive sitemap located at root.
- [x] **Robots.txt**: Directives for crawlers and sitemap location.
- [x] **Canonical Tags**: Ensure self-referencing canonicals to prevent duplicate content issues.
- [ ] **Favicon & App Icons**: High-res favicons for all devices.
- [ ] **HTTPS/SSL**: Enforce HTTPS redirects.
- [ ] **Mobile Responsiveness**: Test on Google Mobile-Friendly Test.

## **2. On-Page Optimization**
- [ ] **Title Tags**: unique, keyword-rich, < 60 characters.
- [ ] **Meta Descriptions**: compelling, concise, < 160 characters.
- [ ] **Heading Structure (H1-H6)**: proper hierarchy, H1 containing primary keyword.
- [ ] **Image Alt Text**: Descriptive alt text for all images.
- [ ] **Content Quality**: Eliminate thin content; aim for depth and expertise.
- [ ] **Internal Linking**: Clean anchor text linking to relevant internal pages.

## **3. Structured Data (Schema.org)**
- [x] **Organization Schema**: Company info across the site.
- [x] **WebSite Schema**: Search box potential action (if applicable).
- [x] **BreadcrumbList**: For navigation paths.
- [x] **LocalBusiness**: If physical locations exist.
- [x] **Article/BlogPosting**: Rich results for blog content.
- [x] **Service Schema**: Detailed markup for service offerings.
- [ ] **FAQPage Schema**: For Frequently Asked Questions sections.

## **4. Performance & Core Web Vitals**
- [ ] **LCP (Largest Contentful Paint)**: < 2.5s.
- [ ] **FID (First Input Delay)**: < 100ms.
- [ ] **CLS (Cumulative Layout Shift)**: < 0.1.
- [ ] **Image Optimization**: WebP format, lazy loading (except LCP element).
- [ ] **Code Splitting**: Dynamic imports for heavy libraries.

## **5. Off-Page & Authority**
- [ ] **Social Profiles**: Linking to official social media channels.
- [ ] **Backlink Strategy**: High-quality industry directories, guest posting.
- [ ] **Google My Business**: Claim and verify listing.

## **6. Monitoring & Analytics**
- [ ] **Google Analytics 4**: Tracking configured for conversions.
- [ ] **Google Search Console**: Property verification, sitemap submission.
- [ ] **Bing Webmaster Tools**: Setup and verification.
