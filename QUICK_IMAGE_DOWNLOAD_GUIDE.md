## Quick Download Process

### Step 1: Visit Unsplash
```
https://unsplash.com
```

### Step 2: Search for Each Industry
Use the keywords provided above

### Step 3: Select Images
- Choose high-resolution (at least 1200x800)
- Look for blue-toned, professional images
- Ensure clean, modern aesthetic
- Check license (Unsplash is free for commercial use)

### Step 4: Download
- Click "Download free"
- Images come in high resolution

### Step 5: Optimize
Use online tool: https://squoosh.app
- Upload image
- Select WebP format
- Adjust quality to 80-85%
- Resize to 1200x800 if needed
- Download

### Step 6: Rename & Place
```powershell
# Navigate to public folder
cd d:\VelDurSen\public\images\industries\

# Copy downloaded files here with correct names
```
